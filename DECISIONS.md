Root cause of the ~31k tokens/company: with 3–5 companies per agent, context accumulates *within* an agent — company 5 pays to carry companies 1–4's search results in every turn (~quadratic). Fixes: (1) **`perAgent` default 1** so each agent's context stays flat; (2) a hard **research budget** in the prompt — max 3 searches, max 2 WebFetch and only when snippets can't answer a field; (3) agents now read only `researcher_brief.md` + `anchors.md` (frame.md dropped from the read list); (4) justifications shortened to ≤10 words and `f_notes` made optional; (5) the prompt itself trimmed since it is now repeated per company.
