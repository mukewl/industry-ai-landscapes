- **2026-07-13 · D11** — **Token-cost investigation** (user: "it's taking a lot of tokens"). Hypothesis was that context accumulates *within* an agent, so `perAgent` was cut 5→1. **Measurement disproved it**: perAgent=5 cost 27k tokens/company (batch 01, 10 companies) while perAgent=1 cost **68k/company** (canary, 3 companies) — 2.5× worse. Real driver: every agent turn re-sends the whole context (system prompt + tool definitions + schema + brief), so fixed overhead is paid **per turn**; more agents multiplies it rather than amortizing it, and grouping similar companies lets one search inform several. **Settled on `perAgent` = 4 with thematically-grouped chunks**, plus the retained wins: hard research budget (max 3 searches, max 2 WebFetch and only when snippets can't answer), agents read only `researcher_brief.md` + `anchors.md`, ≤10-word justifications, `f_notes` optional. Lesson: measure before optimising — the intuitive fix was backwards.
