# sessions/ — one log per working session

Named `YYYY-MM-DD-session-NN.md`. Written at the end of every session (and updated mid-session for long ones — context can be lost at any moment; the file system is what survives).

Structure that worked: **What was done** (numbered), **Key surprises**, per-milestone subsections when a session has several rounds, **Open threads**. The latest file here is the third thing a resuming model reads (after PROJECT.md and STATE.md).
